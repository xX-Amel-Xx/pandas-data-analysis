Exercícios de Pandas
Este repositório reúne exercícios práticos desenvolvidos para estudar os principais conceitos da biblioteca Pandas, utilizada para manipulação e análise de dados em Python.
Tecnologias utilizadas
* Python 3
* Pandas
* VsCode
  
=======Exercícios=======

__Exercício 1 - Visualizando os dados__

Exibir o DataFrame completo.
Exibir as duas primeiras linhas.
Exibir as três últimas linhas.

__Exercício 2 - Informações__

Descobrir a quantidade de linhas.
Descobrir a quantidade de colunas.
Verificar o tipo de dado de cada coluna.

__Exercício 3 - Selecionando colunas__

Exibir apenas as colunas Nome e Salário.
Exibir apenas a coluna Cidade.

__Exercício 4 - Selecionando linhas__

Exibir apenas a primeira linha.
Exibir apenas a terceira linha.
Exibir as linhas da segunda até a quarta.

__Exercício 5 - Filtros__

Pessoas com salário maior que 3000.
Pessoas que moram em Brasília.
Pessoas com idade menor que 30.

__Exercício 6 - Dois filtros ao mesmo tempo__

Pessoas que moram em Brasília e possuem salário maior que 3000.

__Exercício 7 - Estatísticas__

Média dos salários.
Maior salário.
Menor salário.
Média das idades.
__Exercício 8 - Ordenação__

Ordenar pelo salário (menor para maior).
Ordenar pelo salário (maior para menor).
Ordenar pela idade.

__Exercício 9 - Criando coluna__
Criar uma nova coluna chamada Salario_Anual, calculando:
Salário × 12

__Exercício 10 - Alterando valores__

Alterar o salário da Amanda para 3000.

__Exercício 11 - Contagem__

Contar quantas pessoas existem em cada cidade utilizando value_counts().

__Exercício 12 - Maior salário__

Exibir apenas a pessoa que possui o maior salário.

__Exercício 13 - Menores de 30 anos__

Exibir apenas:
Nome
Cidade
das pessoas com menos de 30 anos.

__Exercício 14 - Adicionando uma linha__

Adicionar um novo registro:
Nome: Carlos
Idade: 35
Cidade: Salvador
Salário: 4500

__Exercício 15 - Removendo uma coluna__

Remover a coluna Cidade.

========Conceitos praticados=======
Criação de DataFrames
Visualização de dados (head() e tail())
Seleção de linhas e colunas (loc)
Filtros simples e compostos
Ordenação de dados (sort_values())
Estatísticas (mean(), max(), min())
Criação e alteração de colunas
Contagem de valores (value_counts())
Adição e remoção de dados
Manipulação de DataFrames

=======Objetivo=======
Este projeto foi desenvolvido com o objetivo de praticar os fundamentos do Pandas e fortalecer os conhecimentos em manipulação e análise de dados utilizando Python. Os exercícios fazem parte da minha jornada de aprendizado e da construção do meu portfólio para oportunidades na área de Tecnologia e Dados.
Essa versão fica com um padrão bem parecido com os repositórios de estudo que recrutadores costumam ver no GitHub: organizada, objetiva e profissional, sem listar código desnecessário no README.
